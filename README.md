# Live Editor

Edit a GitHub Pages site visually. Every change is written back into the
code and saved to GitHub automatically.

1. Paste a GitHub Pages link (for example `https://dineshmerugu06.github.io/footwear-v2/`).
2. Press Load site.
3. Click an element, change its text or colour, drag to move it.
4. Every change goes in the Change Log and is saved to GitHub
   (needs a fine-grained token with Contents Read and write, entered
   inside the tool only — it stays in your browser).
5. GitHub Pages rebuilds in about 1 minute. Hard refresh the live link.

Live: https://dineshmerugu06.github.io/live-editor/
